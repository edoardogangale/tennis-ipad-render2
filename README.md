# Tennis iPad Reborn

Multiplayer 3D tennis game optimized for iPad, using Node.js, Express, Socket.IO and Three.js.

## Deploy on Render

Create a new Render Web Service from this repository.

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/health`

The included `render.yaml` can also be used with Render Blueprint deployment.

## Local

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Multiplayer

Share the Render URL with your friend. Both players join the same automatic room.
